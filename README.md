# freeCodeCamp Responsive Web Design Projects
![Responsive Web Design Certification](https://img.shields.io/badge/freeCodeCamp-Responsive%20Web%20Design-brightgreen?logo=freecodecamp)

This repository contains all the projects I completed as part of the **Responsive Web Design Certification** offered by [freeCodeCamp](https://www.freecodecamp.org/). These projects focus on building responsive and accessible websites using only **HTML** and **CSS** — no JavaScript involved.

## 🧠 What You'll Find Here

📁 Each folder represents a separate project I built during the course:

- `Proj1/`, `Proj2/`, etc.  
  These are practice projects I created while progressing through the different sections of the curriculum.

- `Certification_Project_1/` to `Certification_Project_5/`  
  These are the five **required projects** you must complete to earn the certification. Each one follows a set of user stories defined by freeCodeCamp.

## 📜 Certification Projects Overview

1. **Tribute Page**  
2. **Survey Form**  
3. **Product Landing Page**  
4. **Technical Documentation Page**  
5. **Personal Portfolio Webpage**

All of these are built using semantic HTML and responsive CSS techniques like Flexbox and CSS Grid.

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Flexbox, Grid, Media Queries)  
- No JavaScript

## 🎓 About the Certificate

After completing all five certification projects and passing the provided test cases, I was awarded the **Responsive Web Design Certificate** by freeCodeCamp. This certificate demonstrates a solid understanding of creating accessible and responsive web pages using only HTML and CSS.
